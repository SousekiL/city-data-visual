# City Data Visual

公开作品集 / Public portfolio of vertical city, terrain, population, and cultural-geography visualizations.

本仓库仅发布成图和简短作品说明。渲染代码、研究笔记、参数合同、原始数据与中间产物均保留在本地，不随仓库发布。

This repository intentionally contains only published images and brief portfolio metadata. Rendering code, research notes, parameters, raw data, and intermediate outputs remain local.
