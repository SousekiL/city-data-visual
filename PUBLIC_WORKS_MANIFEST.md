# Public works manifest / 公开作品清单

`public-works/` is the complete public image collection for this repository. Images published before 2026-09-24 are retained as original files. Images added on 2026-09-24 (`.webp` files in the collections below, except `building-age/`) are WebP web copies (quality 88, original dimensions) of local finals; animation stills are single decoded frames of the delivered videos.
